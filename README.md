## Projects

- [Meteor Echo Station](https://github.com/alexwastaken/meteor-scatter-sdr) — Receive-only meteor-scatter monitoring system built with Python and NumPy. Processes continuous RTL-SDR I/Q samples using FFT and band-power analysis, detects transient rise-and-decay patterns, and checks surrounding frequencies for interference. A bounded 30-second I/Q buffer provides context for saved candidate recordings, accompanied by JSON metadata and SHA-256 integrity hashes. A browser dashboard streams power traces, a waterfall display, and demodulated FM audio. Includes a synthetic-data mode and automated tests; detections remain unconfirmed candidates.
- [DroidFun](https://github.com/alexwastaken/DroidFun) — Desktop controller and RP2040 firmware for USB desk companions, built with Rust, Tauri, React, and TypeScript.
